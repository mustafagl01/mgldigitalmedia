### A. Accent colour system — Moved: yes

Use a semantic dual-accent system, not green-led:

- Ground: `#F4F6F8`
- Surface: `#FFFFFF`
- Carbon: `#171A1F`
- Muted text: `#667085`
- Borders: `#D9DEE7`
- Active/routing cobalt: `#3155D9`
- Approved green: `#197052`
- Awaiting amber: `#B7791F` — status dots only

Cobalt represents movement; green appears only after approval. This protects the metaphor and avoids lime/warm-paper drift.

### B. Fonts — Moved: no

Use **IBM Plex Sans + IBM Plex Mono**.

Plex Sans handles all headings, body text, buttons, names and values. Plex Mono is restricted to short status labels, timestamps, route IDs and simulator annotations. Never use mono for mobile body copy or important values.
